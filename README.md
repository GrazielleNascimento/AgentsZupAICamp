Projeto Currículo
Este repositório reúne um projeto de currículo digital, desenvolvido para facilitar a criação, edição e personalização de currículos em formato markdown. O objetivo é oferecer uma solução prática tanto para quem está começando quanto para profissionais que desejam atualizar seu CV de forma rápida e eficiente.

Sobre o Projeto
Aqui você encontra um prompt de geração de currículos em Markdown, que pode ser preenchido conforme a necessidade do usuário. O projeto foi pensado para ser simples de utilizar, permitindo que qualquer pessoa possa gerar um currículo bem estruturado e visualmente agradável.

Estrutura do Repositório
Versões do Código: O repositório conta com diferentes versões do código, permitindo acompanhar a evolução do projeto e escolher a implementação que melhor se adapta ao seu perfil ou necessidade.
Documentação: Instruções para construção e validação do prompt.
